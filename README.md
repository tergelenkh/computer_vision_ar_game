# Gesture-Controlled AR Game
Project Description:

This project is a computer vision-based interactive game that allows users to control gameplay using hand gestures instead of traditional input devices such as a keyboard or mouse.
The system uses a webcam to detect and track hand movements in real time. Recognized gestures are mapped to in-game actions such as movement, selection, or interaction. Additionally, augmented reality (AR) elements are overlaid on the camera feed to create an immersive and engaging user experience.
The goal of this project is to combine computer vision and AR techniques to develop a natural and intuitive human-computer interaction system. It also demonstrates practical applications of gesture recognition in gaming and interactive systems.
